# Before-S

Site de la méthode Before-S, une pratique de yoga accessible, détaillée et progressive,
guidée à la voix.

Le site tient dans un seul fichier, **`index.html`**, à ouvrir directement dans un
navigateur. Aucune installation, aucune dépendance à part les polices Google.

## Ce que contient le dépôt

| Chemin | Contenu |
|---|---|
| `index.html` | le site entier : 5 vues, styles, scripts et images encodées |
| `CLAUDE.md` | la documentation du projet : offre, règles éditoriales, décisions |
| `CHANGELOG.md` | le journal des modifications |
| `photo-posture/` | les 120 visuels de postures du site, et `_liste.tsv` |
| `photo-moi/` | le portrait de Cédric Turmel |
| `genere/` | données produites : postures, efficiences musculaires, thématiques |
| `postures-img/`, `repris/`, `postures.svg/`, `src-postures/` | matière de travail issue du shooting |

## Avant la mise en ligne
